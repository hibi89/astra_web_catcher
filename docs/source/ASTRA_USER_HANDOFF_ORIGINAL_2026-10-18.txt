너를 ‘아스트라’라고 부르고 있다. 답변은 짧고 실행 중심으로 해줘.

[목표]
나(사용자) + 너(ChatGPT) + Sol(AI 코딩 도구)이 ‘웹캐쳐’를 개발 중이다.
URL과 내 수동 시연을 바탕으로 기능·데이터 흐름을 분석하고,
독립적인 DB·API·프론트를 생성하는 반자동 개발 보조도구다.
현업에서 검토·수정해 재사용하는 것이 목표다.
원본 서버 코드 추출이나 접근 제한 우회가 목적은 아니다.

[현재 완료]
FastAPI 기반 도서 쇼핑몰 /shop, 채용 사이트 /jobs 구현.
Sol이 최초 구현에 약 22분 소요.
내가 주문·지원 흐름과 새로고침 후 유지 확인.
Sol 보고 기준:
기존 테스트 13/13, 추가 HTTP 병렬 테스트 6/6 통과.
서버 재시작 후 유지, 사용자 격리, 주문 금액·재고,
주문 키 재전송, 동시 주문·중복 지원 방지 검증.
브라우저 자동 UI·Console/Network 검사는 미완료.
이는 상세 명세로 만든 앱이며 범용 웹캐쳐가 완성된 것은 아니다.

[현재 실험]
참고 사이트:
https://daily-dashboard-ldh-1013.clevertide128.chatgpt.site/

일본 셀프 젤네일 시장 비교 대시보드.
메뉴: 대시보드, 태그 분석, 브랜드 비교, 상위 게시물.
브랜드: NAILTOWN, GELME1, OHORA, EDGEU.

내 브라우저에서는 접속 가능.
Sol은 일반 웹 조회·컨테이너 접속 실패했지만,
연결된 Chrome 탭의 화면 내용은 읽었다고 보고했다.
실시간 클릭 관찰·Network 추적은 못 한다.
원본 API 방식·DB 구조·일부 지표 계산식은 미확인.
화면의 ‘n8n 실시간’ 문구만으로 실제 연동을 확정하면 안 된다.

[바로 다음 작업]
아직 젤네일 대시보드 앱은 구현하지 않았다.
내가 ‘전체 → OHORA → NAILTOWN → 전체’로 조작하고,
Sol이 매 단계 탭을 다시 읽어 전후 데이터를 비교한다.
못 읽는 부분만 스크린샷이나 녹화를 제공한다.
다른 메뉴도 확인한 뒤 관찰 사실과 추정을 구분한 명세를 만들고,
별도 작업 공간에서 1차 MVP를 구현한다.
‘최신 보고서 조회’ 버튼은 동작을 확인하기 전까지 보류한다.

[보존 및 판정]
기존 두 앱과 테스트를 덮어쓰지 않는다.
기록 → 분석 → 생성 파이프라인은 아직 연결되지 않았다.
현업 유효성은 수정·검증까지 포함해 직접 개발보다 시간이 줄고,
권한·데이터 무결성 테스트를 통과하는지로 판단한다.
보고서의 주장과 직접 확인한 사실을 구분한다.

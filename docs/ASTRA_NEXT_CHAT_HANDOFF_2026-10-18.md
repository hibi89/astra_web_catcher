## 절대 헷갈리지 말 것

- ASTRA의 목표는 URL 또는 시연 가능한 **임의 참고 사이트의 기능·사용 흐름**을 관찰하여 **사용자 DB/API 스키마와 매핑**, 부족한 필드·산식은 승인을 받고, **독립 백엔드·DB·프론트**로 구현·테스트하는 **재사용 가능한 반자동 개발 보조도구**다.
- **OHORA CSV, 일본 네일 대시보드, Nail Atlas** = 테스트 케이스. ASTRA의 목적은 OHORA 네일 트렌드 분석 서비스 제작 그 자체가 아니다.
- 웹페이지 99% 자동 복제나 보이지 않는 원본 서버 코드 추출, 기존 DB 무단 변경을 약속/추진하지 말 것. 디자인 동일성보다 **기능 정확성/데이터 정확성/재사용**이 목표.
- v1은 목록·검색·필터·상세·등록·수정·삭제·기본 집계까지만. 결제·정산·복잡한 권한은 차기 범위.
- 기존 학습/검증 코드를 삭제·덮어쓰지 말 것: main의 `/shop`, `/jobs`; 연구 브랜치 `nail_dashboard/`; 실험 브랜치 `nail_practice/`; 데이터·고정 스냅샷.
